## How to Play ##

The game starts with an empty 3x3 board.

You play as 'x' and the AI plays as 'o'.

On your turn, input your move in the format: column,row

Example: 2,3 places your symbol in column 2, row 3.

Type exit to quit the game at any time.




Make sure mcts.py exists and is in the same folder as board.py.

Open a terminal or command prompt, navigate to the project folder, and run: 

python tictactoe.py
