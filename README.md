# Tic-Tac-Toe

Task : Develop a Tic-Tac-Toe game featuring an AI player capable of making optimal decisions using the Minimax algorithm with Alpha-Beta pruning. The system should effectively simulate game scenarios to choose the best moves while maintaining computational efficiency. The game should support a configurable n×n grid and adapt to a variety of game configurations. The goal is to build a robust AI opponent that can handle all possible game states with competitive strategies.

This is an open-ended project, giving you the flexibility to explore creative
implementations. Your work will be evaluated based on correctness, efficiency,
solution clarity, and any innovative features or enhancements.

A common approach for developing game AI is combining decision-making
algorithms with optimization techniques. The Minimax algorithm evaluates all
potential moves and their outcomes to determine the best move for the AI player.

To improve efficiency, Alpha-Beta pruning eliminates unnecessary branches in the
decision tree, reducing the computational overhead.

The core system involves:
1. Designing the game board and game logic for an n×n Tic-Tac-Toe.
2. Implementing the Minimax algorithm to simulate possible moves and outcomes.
3. Enhancing the Minimax algorithm with Alpha-Beta pruning for performance optimization.
4. Creating an interactive user interface for human players to interact with the AI.

Python is the recommended language for implementation, with libraries
like pygame or Tkinter for optional graphical interfaces.
